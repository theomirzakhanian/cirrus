# Code of conduct

Be decent to each other. In practice that means a few things.

Talk about the work, not the person who did it. Assume the other person is trying. Don't harass anyone, and don't use slurs or personal attacks, in issues, pull requests, or anywhere else people talk about the project.

If someone breaks these rules, a maintainer can edit or delete their comments, lock a thread, or block them. To report a problem, message theomirzakhanian on GitHub. Reports stay private.
